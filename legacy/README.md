# Legacy versions

Archived earlier versions of No Show 2030. They are not built, type-checked or linted.

| Folder | What it is | Last shipped as |
| --- | --- | --- |
| `src-classic/` | The original 2D planning game. | — |
| `src-3d/` | The 3D campaign game (factory slots, freight lanes, quarters). | Tag `v1-campaign-game` |

To run either one, check out the `v1-campaign-game` tag. It has the full toolchain, including `three@^0.169.0`, which was removed from `main` in the v2 rebuild.
